# No-cost multi-faith source catalogue

Checked 24 October 2026. Runtime catalogue: packages/shared/src/reading-sources.ts.
Free reading access, API access and permission to copy are separate properties.
This catalogue identifies existing source providers; it does not claim completed
in-app integrations or exhaustive coverage of every religious tradition.

| Tradition | Source | Integration route | Current state |
| --- | --- | --- | --- |
| Hinduism | Sanskrit/English Wikisource | Attributed downloaded Gita edition | 700 passages loaded |
| Islam | [Tanzil](https://tanzil.net/docs/Text_License) | Verbatim text download; separate translation license | Source identified; import pending |
| Christianity | [eBible World English Bible](https://ebible.org/find/show.php?id=eng-web) | Public-domain USFM/USFX/download | Source identified; import pending |
| Sikhism | [Shabad OS](https://www.shabados.com/docs/database/) | SQLite/npm database; per-translation checks | Source identified; import pending |
| Judaism | [Sefaria](https://developers.sefaria.org/docs/usage-of-our-name-and-logo) | API/download, approved editions only | Per-edition import pending |
| Buddhism | [SuttaCentral Bilara](https://github.com/suttacentral/bilara-data/blob/published/LICENSE.md) | Selected CC0 translations and root text | Source identified; import pending |
| Taoism | [Wikisource Tao Te Ching](https://en.wikisource.org/wiki/Tao_Te_Ching) | Identified public-domain edition | Edition import pending |
| Confucianism | [Chinese Text Project](https://ctext.org/analects) | Free reading; limited API | External reading; bulk terms need review |
| Jainism | [Jain eLibrary](https://www.jainelibrary.org/) | Hosted books, registration for some downloads | External reading; per-book permission |
| Zoroastrianism | [Avesta.org](https://www.avesta.org/copyright.htm) | Personal hosted reading | External reading; copying prohibited without authorization |
| Shinto | [Kojiki at Sacred Texts](https://sacred-texts.com/shi/kj/index.htm) | Historical hosted edition | External reading; edition terms check |
| Baháʼí | [Official reference library](https://www.bahai.org/library/) | Hosted text subject to [conditions](https://www.bahai.org/legal) | External reading; compliant local edition pending |
| Latter-day Saints | [Official scripture library](https://www.churchofjesuschrist.org/study/scriptures?lang=eng) | Hosted reading | External reading; reuse terms separate |

No subscription or paid API has been selected. Providers can change their services;
network failures must show a useful error and never manufacture replacement text.
