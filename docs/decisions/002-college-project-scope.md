# College-project scope clarified by the maintainer

The user clarified on 24 October 2026 that this is a college project, an overhaul
of the existing repository. It is not a new business or an independent scripture
publishing operation. Use existing models/services and published text sources.

The user then explicitly retained a multi-faith reader: sources should be arranged
through free APIs, downloadable editions or other free reading hosts. The reader
must not be scoped permanently to the Gita alone.

Implementation priorities: a working multi-faith reader/source selector, search,
defensible quotation matching with context, practical speech input/TTS integration,
usable UI, deployment on Render or Oracle and final owner testing. The large PDF
remains a reference roadmap. Continuous voice, broad scholarly judgments and
organization/community operations are future scope, not submission promises.

No paid API subscriptions or paid hosting upgrades. Reuse permitted downloaded
texts where possible; read local copies without a live scripture API dependency.
For sources that allow reading but not copying, show an explicitly labelled link
to their reading site. Do not count external-only text as locally searchable or
verified. Preserve source-specific language and edition availability.

There is no universal free API for every religion/edition/language. Keep a source
catalogue with accurate access and integration status rather than claiming every
religion or translation is already loaded.
