# Expanded religion library and study continuity

The maintainer requested substantially broader actual content, religious tabs,
book/section navigation, all available licensed translations, markers/notes and
more useful conversation continuity. English is the priority, with other available
human editions and explicit optional machine-assisted study translations.

Keep Explore / Read / Study. Read uses one religion selector and a single active
collection view, grouped into relevant book families. A source link is not an
imported work. Show actual edition and coverage; do not label English translations
as original Hebrew, Sanskrit, Prakrit or Chinese. Reference numbering comes from
the source; platform paragraph locators are identified as such.

Machine-assisted translations never replace canonical text or appear as approved
human translations. They require a deliberate request, applicable source rights,
an unreviewed label and visible source attribution. Edition restrictions still
apply. No paid resource or model fine-tuning is authorized. Groq answers use source
retrieval and selected saved conversation context, not permanent learning from
chats. Memory stays device-local with visible context and an off switch.
