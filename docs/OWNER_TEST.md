# Final owner test

Open https://scripture.129-225-126-21.sslip.io/ on your computer and phone.
The site has three main destinations: Explore, Read and Study.

1. **Explore:** search `BG 2.47`, try a phrase from its translation, and verify a
   copied quotation. Switch to Ask: “What does BG 2.47 say about the results of
   action?” Follow with “How does that differ from avoiding work?” Check the
   displayed evidence and citations. Reopen the conversation after reloading;
   try renaming, deleting and pausing history.
2. **Read:** use the chapter/verse picker. Open Compare human translations on a
   Gita passage; BG 2.43 demonstrates an explicitly combined source range.
   Switch editions, copy the passage and download its attributed PNG. Open
   context and the connection graph/list; follow a neighbouring passage.
3. **More texts:** read Quran 2:255 in Arabic and Dhammapada chapter 2, beginning
   at verse 21. Check the source notices. Quran 1:1 offers one human recording
   covering the complete Al-Fatiha. In Read, switch among the 13 tradition tabs;
   open the Ramayana, a Veda, a Jain sutra, Tanakh Genesis and a Bible book. Use
   the language filter and available Hindi edition. Long chapters have pages.
   On a bookmark, add a colour and private note, then reload. Mark read and use
   Continue reading. On an eligible historical English passage, request a study
   translation; confirm its unreviewed label and separate source edition. Restricted
   editions must not offer that action. Enable saved-conversation context only if
   you want selected earlier exchanges sent with Ask.
4. **Study:** bookmark a passage, mark it read, create a daily reading plan,
   practice recall, try the word-order quiz and schedule a revision. Reload and
   inspect the activity grid. Share a classroom set link in another browser.
5. **Offline and voice:** download a work, open its offline reader, disconnect
   the network and read/search it. Restore the network. Test microphone input
   with your browser's consent control; review or edit the transcript before
   sending. Try explanation playback if an installed local voice is available.

Check light/dark appearance, text size, keyboard navigation and mobile scrolling.
Use a passage's Report an error link for a text/attribution problem. Describe a
functional issue with the URL, browser, action and expected result.

Guest history, bookmarks, plans and activity belong to the browser profile. Free
accounts synchronize saved reading across devices; sign in and reload to retrieve
the latest saved version. Clear controls remain available.
Ask sends selected context to Groq; free quotas can temporarily stop answers.
Meaning search, speech matching and AI interpretations are experimental. No
scholarly approval, pronunciation assessment or complete all-religion corpus is
claimed. Actual microphone and voice quality are part of this owner test.

## Individual account checks

Create an account using a unique username and a password of at least 12 characters;
save the recovery code. Bookmark and annotate a passage, mark it read, create a reading
plan, and submit an Explore search. After the save completes, sign in from another
browser and confirm your dashboard and history. Sign out and confirm the private
entries disappear. Guest entries are separate and only import via the Study control.
Try recovery with your saved code; existing sessions should expire and the new code
replaces the old one. Delete a test account in settings using its password.

## Email and Google access

Use the separate Sign up header link to create an account with an email and a new
website password (or choose Use a username instead). On Sign in, entering an unused
email and continuing should open Sign up with that address preserved. An existing
address should request the website password; a wrong password must not create a
second account. Gmail addresses also work as normal email logins. One-click Continue
with Google appears only after OAuth setup. When enabled, verify Google's account
chooser opens in a full browser and the completed login returns to your own Study
dashboard. Existing password accounts must explicitly link Google from settings.
